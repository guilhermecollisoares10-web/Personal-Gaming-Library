# Personal Gaming Library

Personal Gaming Library é uma aplicação web desenvolvida para organizar, visualizar e gerenciar jogos de forma estruturada. O projeto oferece uma interface limpa, suporte a modo claro/escuro, exibição de informações do sistema e armazenamento local dos dados do usuário.

## Funcionalidades

- Biblioteca completa de jogos adicionados pelo usuário.
- Formulário para cadastro de novos jogos.
- Página dedicada para estatísticas de desempenho.
- Modo claro e escuro.
- Armazenamento dos dados utilizando LocalStorage.
- Navegação por páginas independentes.
